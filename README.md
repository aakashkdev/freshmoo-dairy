# 🌿 FreshMoo Dairy - Farm Fresh Dairy Products

> Delivering pure, natural dairy products straight from our farm to your doorstep. FreshMoo Dairy is a family-owned dairy farm dedicated to providing high-quality milk, paneer, ghee, curd, lassi, and more using traditional Indian methods.  

---

## 🔥 Features

- ✅ Responsive React.js website  
- ✅ Smooth animations using **Framer Motion**  
- ✅ Fully functional **FAQ** and **Testimonials** sections  
- ✅ Attractive **Products** grid with hover effects and gradient price tags  
- ✅ Contact section with all details (phone, email, location, hours)  
- ✅ Modern, clean, and colorful UI  

---

## 🛠️ Tech Stack

- **Frontend:** React.js  
- **Styling:** Tailwind CSS  
- **Animations:** Framer Motion  
- **Icons:** React Icons  
- **Deployment:** GitHub Pages
